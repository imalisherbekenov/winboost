# WinBoost 4.0

## Обновление безопасности зависимостей сайта

- Next.js обновлён до 15.5.25; вложенные PostCSS и Sharp закреплены на 8.5.28 и 0.35.4.
- Vercel устанавливает зависимости командой npm ci из проверенного package-lock.json.
- Оформление Obsidian, функции сайта и EXE WinBoost 4.0 сохранены.

## Obsidian — обновление оформления 4.0

- Графитовые поверхности и акценты шампань в приложении, сайте и значке сайта.
- Нейтральные показатели и заголовки; отдельные семантические цвета риска и результатов.
- Сатинированное 3D-ядро с мягким бликом, новые кнопки и сдержанный блок загрузки.
- Анимация учитывает настройку уменьшения движения.

## Приложение

- Новая тема Obsidian с акцентом шампань, переработанный обзор системы.
- CPU, оперативная память и свободное место на диске обновляются каждые 2 секунды.
- Сценарии «Повседневный», «Игровой», «Приватность». В наборы входят только обратимые действия низкого риска.
- Поиск по названию, описанию и категории; фильтры риска; счётчик выбранного, включая скрытые фильтром действия.
- Экспорт глубокого анализа в JSON через выбор файла.
- Необратимые действия изначально сняты с выбора и требуют подтверждения.
- Остановка между действиями: текущая операция завершается, остальные пропускаются. Уже выполненные изменения не отменяются автоматически.
- Отчёт каждой сессии с результатом каждого действия, ошибками, пропусками и путём к снимку.
- Ошибки старых модулей, сообщённые через журнал, учитываются в результате выполнения.
- Ошибка чтения реестра больше не трактуется как отсутствие значения. Ошибки получения служб, задач, питания или DNS прерывают создание снимка и запуск изменений.
- Снимки изменений и отчёты записываются атомарно. Существующий первичный снимок не перезаписывается.
- Подтверждение восстановления с пояснением последствий. Пропуски при восстановлении видны в статусе.
- Изменение плана питания и визуальных эффектов теперь отмечено как требующее внимания и исключено из умеренных сценариев.

## Сайт

- Полностью новая адаптивная композиция, объёмное ядро WinBoost на CSS 3D, реакция на курсор.
- Появление разделов при прокрутке, анимированная визуализация сигнала и карточки снимков.
- Интерактивное демо: анализ, сценарии, выбор, проверка, применение и восстановление.
- Мобильное меню, клавиатурная навигация, фокус, поддержка reduced motion.
- Загрузка новой локальной EXE-сборки; основной CTA не ведёт на старый публичный релиз.
- Статический экспорт без внешних шрифтов и новых библиотек анимации.
- Команда `npm start` запускает локальный сервер статического экспорта.

## Проверка и границы

Python-тесты проверяют движок и взаимодействие компонентов Dear PyGui без системных оптимизаций. Интеграционный тест с отдельным ключом HKCU может пропускаться в ограниченной среде. Браузерное демо работает только с демонстрационными данными.

Сборка локальная, без цифровой подписи. Реальное применение всех твиков на Windows 10/11 и перезагрузка после них требуют отдельного прогона на тестовой машине. Прирост производительности не измерялся. Сайт публикуется в связанном проекте Vercel из ветки `main`. Отдельный GitHub Release для 4.0 не создавался.
