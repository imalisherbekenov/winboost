# Архив ассетов

Уникальные файлы из папок, которые существовали до сборки проекта в один
репозиторий (`antigravity/WinBoost_Source`, `antigravity/WinBoost_Site`,
`Новая папка/WinBoost_Source`). Сами папки удалены 31 августа 2026.

| Файл | Что это |
|---|---|
| `app_*_mockup.png` | Концепт-рендеры интерфейса, сгенерированные для старого лендинга. Показывают несуществующий продукт: версия «v3.1», навигация Dashboard/Cleanup/Privacy/Gaming, выдуманные показатели. На сайте не используются — расходятся и с реальным приложением, и с текущей дизайн-системой. |
| `WinBoostGUI-onedir.spec` | Второй PyInstaller-спек, сборка каталогом вместо одного файла. Рабочий спек проекта — `app/WinBoost.spec` (onefile). |

Не попало сюда намеренно: пять байт-идентичных PNG по 15 КБ
(`gui_screenshot.png`, `audit_*.png`) — пустой чёрный кадр, неудавшийся снимок.

Исходники всех трёх старых GUI достаются из истории git, коммит `fc3d3af`:
`git show fc3d3af:app/WinBoostGUI_old.py` (CustomTkinter, 775 строк),
`git show fc3d3af:app/WinBoostQt.py` (PySide6, 431 строка).
