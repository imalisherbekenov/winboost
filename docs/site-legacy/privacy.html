🔒 Политика конфиденциальности

Последнее обновление: 1 мая 2026

1. Какие данные мы собираем

WinBoost не собирает, не передаёт и не хранит ваши персональные данные. Приложение работает полностью локально на вашем компьютере.

2. Как работает WinBoost

WinBoost анализирует настройки Windows (реестр, службы, план электропитания) и предлагает оптимизации. Все операции выполняются локально. Никакие данные не отправляются на внешние серверы.

3. Бэкапы

Резервные копии настроек создаются и хранятся только на вашем компьютере в формате JSON. Они никуда не передаются.

4. Сайт winboost

Наш сайт не использует cookies для отслеживания. Мы не встраиваем рекламные трекеры. Хостинг-провайдер может собирать стандартные серверные логи (IP-адрес, user-agent) для технического обслуживания.

5. Сторонние сервисы

  • Google Fonts — для загрузки шрифтов Inter и JetBrains Mono
  • GitHub — для хостинга файла WinBoost.exe

Эти сервисы имеют свои политики конфиденциальности.

6. Безопасность

WinBoost не требует регистрации, аккаунтов или онлайн-подключения. Приложение запрашивает права администратора только для применения системных настроек.

7. Обновления политики

Мы можем обновлять данную политику. Актуальная версия всегда доступна на этой странице.

8. Контакты

Вопросы по конфиденциальности: свяжитесь с нами.
