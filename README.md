# WinBoost

Оптимизатор Windows: анализирует систему, показывает что изменится, применяет
выбранное и умеет откатить назад.

[**Скачать 3.1**](https://github.com/imalisherbekenov/winboost/releases/latest) ·
[winboost.vercel.app](https://winboost.vercel.app)

Windows 10/11 x64. При первом запуске запрашивает права администратора и
снимает первичный снимок системы.

## Как это устроено

**Ничего не применяется молча.** Любой путь — мастер, экспертный режим,
быстрая оптимизация — сначала выводит экран проверки: список действий с
уровнем риска, чекбокс у каждого, отдельная секция необратимых и сводка того,
что попадёт в снимок. Кнопка «Применить» — только после этого.

**Откат покрывает не только реестр.** Снимок пишет значения реестра, тип
запуска и состояние служб, состояние задач планировщика, активный план
электропитания, DNS на адаптерах и список установленных UWP-пакетов.
Первичный снимок создаётся один раз и не перезаписывается, поэтому вернуться
можно и к предыдущему состоянию, и к исходному.

**Что вернуть нельзя** — удаление UWP-приложений и очистку файлов. Такие
действия помечены как необратимые и вынесены на экране проверки в отдельную
секцию с предупреждением; после восстановления они перечисляются в списке
пропущенных.

10 модулей, 55 действий: приватность, службы, игры, сеть, автозагрузка,
очистка, деблоат, обновления, контекстное меню, CS2.

## Структура

```
app/                Приложение (Python 3.14, Dear PyGui)
  WinBoostGUI.py    Интерфейс: 8 экранов
  icons.py          18 штриховых глифов на примитивах DPG
  modules/          Модули оптимизации + движок снимков (backup.py)
  assets/fonts/     Inter и JetBrains Mono, едут в сборке
  tests/            pytest, 22 теста
site/               Лендинг (Next.js 15 + Tailwind v4)
docs/
  design/           Дизайн-система, знак, иконка приложения
  archive-assets/   Уникальные файлы из папок до сборки проекта
```

## Разработка

```bash
cd app && pip install -r requirements.txt && python WinBoostGUI.py
```

```bash
cd app && python -m pytest tests/ -q
```

```bash
cd app && powershell -ExecutionPolicy Bypass -File build.ps1
```

Сборка читает версию из `APP_TITLE` в `WinBoostGUI.py` — это единственное
место, где она указана.

Снять скриншоты всех экранов без открытия окна:

```bash
cd app && python WinBoostGUI.py --capture-all theme_previews/final
```

Сайт:

```bash
cd site && npm install && npm run dev
```

## Что стоит знать при доработке

- **Консоль Windows отдаёт OEM-кодировку**, а не UTF-8. Внешние команды
  вызываются только через `modules/winshell.py` — он декодирует кодеком `oem`
  и подавляет всплывающие окна консоли. Прямой `subprocess.run` с
  `encoding="utf-8"` уронит декодер на русской системе.
- **У Dear PyGui нет примитива произвольной дуги** — глифы в `icons.py`
  аппроксимируют дуги ломаной через общий хелпер.
- **Обращение к API Dear PyGui до `create_context()`** роняет процесс нативно,
  без трейсбека.
- **Instrument Serif не содержит кириллицы** — заголовки набраны Inter SemiBold.
- Действия объявляют, что трогают, в поле `effects`; снимок собирается из него.
  Добавляя действие, заполняйте `effects` честно, иначе изменение не откатится.
- Поле `icon` обязано быть именем из `icons.GLYPHS` — это проверяется тестом.
